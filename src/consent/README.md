# consent/

ecosystem_inclusion, terms_price) — zrcali `consent_records` entiteto iz
`docs/data_model.md`. Vir resnice za soglasja je sicer lokalni CM (glej
`cm_connector_save_consent()`); tu se hrani samo audit kopija ob dejanski aktivaciji.
