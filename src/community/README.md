# community/

CM Community: opt-in mreža neodvisnih CM namestitev za skupno iskanje,
`public_projection` objavo (glej `docs/data_model.md → public_properties/units`)
in referral capability (`referrals`, `community_search_log`). Neodvisno od
`ota_connectivity` service opt-ina — Community deluje tudi za namestitve brez
OTA API-ja (glej `docs/community_and_shared_services.md` v CM repojih,
addendum §24).

**Not yet implemented.** Ni portala, ni javnega search API-ja — samo shema
readiness (addendum §32, točka 10: "ne implementiraj še celotnega
Community/AI produkta – barebone mora biti samo ready for it").
